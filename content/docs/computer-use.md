电脑操作（Computer Use，简称 CU）让 DSH 的 Agent 操作**没有 API 的 Mac 应用** —— 只要有界面，它就能读、能点。它由两部分组成：

| 组件 | 作用 |
| --- | --- |
| KimiCU.app | 真正执行操作：读取界面、在后台投递点击与键盘输入。从 Kimi 官方渠道安装 |
| `dsh-kimi-computer-use` 插件 | 把 KimiCU 接入 DSH，发布为 `mcp__cu__*` 工具，并附带操作技能 |

DSH 会随插件启动和停止 KimiCU 的 MCP 进程，但不会下载、安装或更新 KimiCU.app 本身。

## 开启步骤

1. 从 **Kimi 官方渠道**安装 KimiCU.app，并保持它在运行。
2. 在「系统设置 → 隐私与安全性」里给 **KimiCU.app** 授予（不是授予 DSH）：
   - **辅助功能**（读取界面结构、投递输入）
   - **屏幕录制**（截图）
3. 安装插件，二选一：
   - Mac App：打开「**设置 → 电脑操作**」一键安装。这一页还会显示 KimiCU 是否已安装、是否有新版本，以及两项授权状态，并可直达系统设置。
   - 命令行：`dsh plugin --profile web add dsh-kimi-computer-use`，然后重启 dsh 服务。
4. 回到 DSH，直接说「帮我在某某应用里……」。

权限随时可以在系统设置里收回。KimiCU 的更新由它自带的更新器完成，替换前会校验签名与 Apple 公证。

## 工具一览

开启后，Agent 会获得以下 **11 个** `mcp__cu__*` 工具。

| 工具 | 作用 |
| --- | --- |
| `list_apps` | 列出正在运行的应用（名称、bundle id、pid） |
| `get_app_state` | 截图与可访问性树，可只取其一；返回带索引的节点 |
| `click` | 按节点索引或截图坐标点击；不移动真实指针 |
| `drag` | 从一点拖到另一点 |
| `drag_paths` | 一次调用投递多条鼠标路径，用于绘制与连续手势 |
| `scroll` | 按页或按行滚动，也可滚到指定节点 |
| `type_text` | 输入 Unicode 文本，可先清空再输入，可带回车提交 |
| `set_value` | 直接设置控件值（原生控件走 AXValue，Web 控件走后台替换） |
| `press_key` | 按键或组合键（`cmd+a`、`return` 这类写法） |
| `select_text` | 在文本元素里选中一段文本，或定位光标 |
| `perform_secondary_action` | 触发元素的次要 AX 动作，例如弹出上下文菜单 |

## 两种「眼睛」

| 手段 | 提供什么 |
| --- | --- |
| 辅助功能树 | 控件的结构、角色与文本 |
| 截图 | 视觉信息，补齐树里读不到的内容 |

两者结合，既能拿到「这是个按钮」，也能看到「它现在长什么样」。

## 按控件而不是坐标

定位基于控件本身而不是硬编码坐标，所以窗口挪了位置、换了分辨率也不失效，比「点 (120, 480)」稳得多。控件索引来自最近一次 `get_app_state`，这也是为什么它总是先读状态再操作。

## 后台输入，不抢前台

操作在后台投递：**不需要把窗口抢到前台，也不碰你的鼠标指针**。你可以继续用电脑做别的事。

## 危险动作先确认

发送、删除、购买、发布这类不可逆操作，会先说明再做。
