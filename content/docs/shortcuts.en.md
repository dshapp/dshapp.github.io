Press `⌘/` at any time to open the shortcuts panel and see every binding. The most useful ones are below.
## The full list

The in-app shortcut panel (`⌘/`) is the authoritative list. The everyday set is below.

| Action | Shortcut |
| --- | --- |
| New session | `⌘N` |
| New session in this workspace | `⌥⌘N` |
| New workspace | `⇧⌘N` |
| Fork session | `⌘R` |
| Archive session | `⌥⌘A` |
| Previous / next session | `⌥⌘←` / `⌥⌘→` |
| Find in this view | `⌘F` |
| Find next / previous | `⌘G` / `⇧⌘G` |
| Find session | `⌥⌘F` |
| Show / hide sidebar | `⌥⌘S` |
| Choose model | `⇧⌘M` |
| Permission mode | `⇧⌘P` |
| Shortcut panel | `⌘/` |

## Why it is built this way

The menu bar is the feature map: every command appears there with its shortcut. Forget a binding and look it up in the menu — there is nothing to memorise.
