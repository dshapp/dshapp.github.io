按 `⌘/` 可以随时打开快捷键面板，一次看全所有绑定。下面是常用的一组。
## 完整列表

应用内按 `⌘/` 打开的快捷键面板是权威列表。常用的一组如下。

| 操作 | 快捷键 |
| --- | --- |
| 新建会话 | `⌘N` |
| 在当前工作区新建会话 | `⌥⌘N` |
| 新建工作区 | `⇧⌘N` |
| 分叉会话 | `⌘R` |
| 归档会话 | `⌥⌘A` |
| 上一个 / 下一个会话 | `⌥⌘←` / `⌥⌘→` |
| 在当前视图中查找 | `⌘F` |
| 查找下一个 / 上一个 | `⌘G` / `⇧⌘G` |
| 查找会话 | `⌥⌘F` |
| 显示 / 隐藏边栏 | `⌥⌘S` |
| 选择模型 | `⇧⌘M` |
| 权限模式 | `⇧⌘P` |
| 快捷键面板 | `⌘/` |

## 为什么这么设计

菜单栏即功能地图：每个命令都在菜单里出现并显示快捷键。忘了绑定就去菜单里找，不用背。
