Android 客户端是同一套会话的手机端，也是远程访问的「扫码那一端」。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 10 或更高 |
| 相机 | 用于扫描配对二维码 |
| 存储 | 约 60 MB |

## 安装步骤

1. 获取 APK 或从应用商店安装（见[下载页](/download/#android)）。
2. 打开应用，进入配对页。
3. 在 Mac 上点「添加设备」生成二维码，用手机扫描。
4. 扫码成功后设备写入白名单，之后靠密钥自证明，不再需要验证码。

## 扫码之后

手机与 Mac 之间会建立一条 Noise 加密通道。手机上看到的是**同一批会话**、同一份文件、同一个工作区 —— 不是另一份远端副本。
