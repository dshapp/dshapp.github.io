这些都是 DSH 会话本身的设置，Mac App 把它们放进了菜单栏和快捷键里，切换不用离开键盘。

## 模型与思考强度

| 操作 | 方式 |
| --- | --- |
| 选择模型 | ⇧⌘M，或在输入框底部点模型名，或输入 `/` |
| 上一个 / 下一个模型 | 菜单「模型」中的对应命令 |
| 调整思考强度 | 菜单中的「思考强度…」「提高思考强度」「降低思考强度」 |

每个会话可以单独指定模型。不同模型在推理深度、速度与工具调用能力上各有取舍，按任务切换即可。

## 权限模式

| 模式 | 允许的操作 | 适合场景 |
| --- | --- | --- |
| 只读 | 读文件、搜索、浏览 | 调研、答疑 |
| 工作区写入 | 在工作区内改文件、跑命令 | 日常改动 |
| 完全访问 | 跳出工作区、更广的系统操作 | 明确知道自己要什么 |

按 ⇧⌘P 切换。权限是**按会话**给的：做调研时别开写入，事情做完把级别收回来。

## Plan 模式

先让 Agent 只读探索、给出计划，你确认后再动手。可以从菜单进入或退出 Plan 模式，计划卡片上还能直接写修订意见。

## 在键盘上处理请求

Agent 请求权限或向你提问时，菜单里有「允许本次请求」「拒绝请求」「跳过提问」，不用伸手去点按钮。
