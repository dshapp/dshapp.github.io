DSH Remote 是 DSH 的微信小程序客户端：手机上看到的是你电脑上的同一批会话，任务仍在电脑上运行。它和 Android App 一样通过 `dsh-mobile-bridge` 插件连回来，电脑不需要开放任何端口。iPhone 用户用它就能远程接管 DSH。

## 打开小程序

{{< miniapp-qr alt="DSH Remote 小程序码" caption="用微信扫一扫，或在微信里搜索「DSH Remote」" >}}

小程序不需要安装，打开过之后可以在微信的「最近使用」里找到它，也可以添加到「我的小程序」。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 手机 | iPhone 或 Android 上的微信 |
| 相机 | 用于扫描配对二维码；没有相机时可以粘贴配对串 |
| 电脑端 | 运行着 dsh，并安装了 `dsh-mobile-bridge` 插件（Mac App 已内置入口） |

## 连上你的电脑

1. 打开配对页：在 Mac App 侧边栏点「**移动端访问**」；不用 Mac App 的话，先运行 `dsh plugin --profile web add dsh-mobile-bridge`，再在浏览器里打开 dsh web 的 `/mobileaccess` 页面。
2. 打开 DSH Remote，首次打开会进入「与电脑配对」引导；点「**扫描二维码**」扫配对页上的二维码。
3. 确认电脑名称（默认是电脑自己报的名字，只在本机显示），点「**连接**」。
4. 连上后，这台手机就是这台电脑的受信设备，之后打开直接用。

二维码 5 分钟内有效、只能用一次；过期了重新生成即可。

> 配对码要在**小程序里**扫。用微信主界面的「扫一扫」去扫配对二维码不会打开小程序。

**没有可用相机？** 在配对页右上角点「**手动输入配对串**」，粘贴 `dshm://` 开头的配对文本，同样完成配对。

## 能做什么

小程序连的是你电脑上的同一个 DSH，功能与 Android App 基本一致：

- 会话列表按工作区分组；置顶、重命名、Fork、归档与恢复都在长按菜单里。
- 实时查看对话、工具调用，以及每轮改动的文件与 diff。
- 处理审批与提问；新建会话、发送消息和附件、插话。
- 查看与停止后台任务；管理自动化任务与插件，调整宿主设置。
- 配对多台电脑，在「设置」里切换。

## 与 Android App 的区别

| | Android App | 微信小程序 |
| --- | --- | --- |
| 任务通知 | 系统推送通知 | 无系统推送；小程序内显示未读角标 |
| 后台连接 | 任务运行时后台保持连接 | 切到后台后断开，回到前台自动重连并补齐进度 |
| 设备私钥 | Android Keystore | 微信本地存储 |
| 打开外部链接 | 交给系统浏览器 | 弹出完整地址，确认后复制 |
| 中转 | 官方中转或自建中转 | 只能连官方中转（受小程序合法域名限制） |

需要任务完成时第一时间收到通知，或者自建了中转，请用 [Android App](/docs/install-android/)。
