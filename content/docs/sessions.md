macOS App 里的会话、工作区与 `dsh web` 是同一份数据，这一页讲的是**在原生 App 里**怎么用得更顺手。

## 会话与工作区

- **工作区**就是 Agent 干活的目录。新建会话时选一个工作区，文件读写和命令执行都发生在它的范围内；同一个工作区可以有多个会话。
- 侧边栏可以**按工作区分组**或显示为单列表，按最近更新、状态或手动排序；常用的会话右键**置顶**。
- 会话可以**分叉**（从任意一步另起一条线）、**归档**与恢复、**导出会话日志**。
- 工具栏的 Workspace 按钮会用你在设置里选定的应用（比如你常用的编辑器）打开当前会话的目录；也可以「在 Finder 中显示工作区」。

## 输入框

| 操作 | 方式 |
| --- | --- |
| 发送 / 换行 | ↩ / ⇧↩ |
| 命令与技能 | 输入 `/`，例如切换模型、权限模式，或调用技能 |
| 引用 | 输入 `@`，引用文件或其它会话，把具体内容带进上下文 |
| 附件 | 把文件或图片拖进输入框、直接粘贴图片，或点回形针按钮；工作区外的文件也会真正上传 |
| 插话 | Agent 运行中继续输入，消息会排队；可以编辑、移除，或立即插话发送 |
| 停止 | 运行中随时停止，已经产生的轨迹会保留 |

中文输入法选词时按回车不会误发送。

## 看清它做了什么

- **工具调用轨迹**：每一次命令、文件改动、截图都可以展开回看，而不是只有一句「已完成」。已结束的轮次会自动折叠成摘要。
- **改动文件卡片**：每轮结束列出改了哪些文件、增删多少行，点开逐文件看 diff。
- **轮次导航**：左侧轮次条按轮跳转，并能翻入更早的历史；⌘F 查找，⌘G / ⇧⌘G 上一个、下一个。
- **轨迹检查器**：时间线展示每一步的耗时与细节，可以缩放、拖动聚焦。
- **用量**：底部可以查看会话统计与 token 用量。

## 内置终端

⌘J 在会话下方呼出终端面板，支持多个标签页。想自己跑一条命令、看看 Agent 改完的效果，不用切到别的窗口。

## 系统通知

在设置里打开通知后，你在忙别的事时，任务完成、失败、等你回答或批准，都会推送 macOS 通知；点一下通知直接回到那个会话。
