描述一个元素很难（「左边那个灰色的按钮」通常不唯一）。圈选元素是**指**而不是**说**。

## 怎么用

1. 在 Chrome 里打开目标页面。
2. 打开 DSH 侧边栏，进入圈选模式。
3. 鼠标移到页面上，候选元素会高亮。
4. 点一下选中，元素的信息会作为上下文进入对话。
5. 顺着这个元素说你要做什么。

## 圈选带进去的信息

选中后带进上下文的不只是「一个按钮」，还包括它在 DOM 里的结构、可见文本与关键属性 —— 这让 Agent 能定位到**具体那一个**，而不是猜一个坐标。

## 什么时候特别有用

| 场景 | 为什么圈选更好 |
| --- | --- |
| 表单字段很多 | 不用描述「第三行第二个输入框」 |
| 动态渲染的列表 | 文字描述不唯一，直接指最准 |
| 只改某一处样式 | 明确指向目标节点 |
