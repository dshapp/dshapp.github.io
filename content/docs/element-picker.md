描述一个元素很难（「左边那个灰色的按钮」通常不唯一）。圈选是**指**，而不是**说**。这个功能在 Chrome 扩展的侧栏里，只装扩展就能用。

## 怎么用

1. 在 Chrome 里打开目标页面，打开 DSH 侧栏。
2. 点「圈选元素」，鼠标移到页面上，候选元素会实时高亮。
3. 点一下选中，**点击处会弹出批注框**：写下你想怎么改，提交；或者继续圈选下一个。
4. 元素以键值卡片的形式进入对话，Agent 可以直接对它点击、填写或读取。

## 带进对话的信息

不只是「一个按钮」，还包括它在页面里的结构、可见文本与关键属性，让 Agent 定位到**具体那一个**，而不是猜一个坐标。在 Mac App 里打开同一个会话，圈选的元素也会显示为易读的键值卡片。

## 带上整个页面

如果要说的不是某个元素，而是整个页面，打开侧栏底部的「携带当前页面上下文」开关，下一条消息会让 Agent 知道你正在看哪个页面。

## 什么时候特别有用

| 场景 | 为什么圈选更好 |
| --- | --- |
| 表单字段很多 | 不用描述「第三行第二个输入框」 |
| 动态渲染的列表 | 文字描述不唯一，直接指最准 |
| 一次改好几处 | 连续圈选、各写一句批注，一起提交 |
| 只改某一处样式 | 明确指向目标节点 |
