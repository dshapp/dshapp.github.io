手机不是「登录」进来的，而是和这台 Mac 建立一条自己的加密通道。

## 配对流程

1. Mac 侧点「添加设备」，生成一次性配对令牌（5 分钟有效，同时只留一枚）。
2. 二维码里带上中转地址、Mac 的公钥与名称、以及令牌。
3. 手机扫码 → 本地生成密钥对 → 用 Noise_IK 连上 → 首条消息携带令牌。
4. Mac 校验令牌（常数时间、单次消费）后把设备公钥写入白名单。
5. 令牌立即丢弃；未配对设备的握手在认证阶段就失败。

## 设备管理

- 每台设备带到期时间，默认 **180 天**。
- 设备列表里的「在线」是**观测**出来的：中转统计手机实际持有的连接数，而不是靠「最后活跃时间」猜。
- 吊销设备会同时挂断它已经建立的连接，立即生效。

| 操作 | 结果 |
| --- | --- |
| 查看已配对设备 | 显示名称、到期时间与实时在线状态 |
| 吊销设备 | 白名单移除，已建立的连接被挂断 |
| 令牌过期 | 5 分钟后自动失效，需重新发起配对 |

## 不开端口

Mac 侧**不监听任何端口**、不写状态文件、不额外起进程。它的生命周期跟随 DSH 服务。
