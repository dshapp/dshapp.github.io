## 为什么要一个原生 App

`dsh web` 是跑在浏览器标签页里的网页：它和几十个网页挤在一起，没有菜单栏，快捷键要和浏览器抢，任务跑完了也不会主动告诉你。

DSH for macOS 换了一种做法 —— **不是网页套壳，也不是跨平台框架**，而是用 SwiftUI 和 AppKit 为 Mac 从头写的原生应用：

- **系统控件**：侧边栏是系统分栏，列表是系统列表，输入框是系统文本控件。你在其它 Mac 应用里形成的习惯，在这里都成立。
- **系统级的手感**：滚动与惯性和系统一致；流式输出、多行输入时界面不会上下跳动；中文输入法选词时不会误把消息发出去。
- **轻**：Apple Silicon 原生构建，安装包约 14 MB，点开就能用。

## 键盘就能驾驭

菜单栏就是功能地图。会话、对话、模型、终端、服务器……几乎所有操作都能在菜单里找到，并标出快捷键：

- 切换模型、调高或调低思考强度、进出 Plan 模式、设定目标。
- **在键盘上处理请求**：允许本次请求、拒绝请求、跳过提问。
- 插话发送、停止生成、从最后一条消息分叉、复制最后一条回复。
- 展开或折叠所有轮次，在轨迹记录之间逐条跳转。

| 操作 | 快捷键 |
| --- | --- |
| 发送消息 / 换行 | ↩ / ⇧↩ |
| 新建会话 | ⌘N |
| 在当前视图中查找 | ⌘F |
| 上一个 / 下一个会话 | ⌥⌘← / ⌥⌘→ |
| 选择模型 / 权限模式 | ⇧⌘M / ⇧⌘P |
| 显示 / 隐藏终端 | ⌘J |
| 打开 Web 端 | ⇧⌘, |
| 快捷键面板 | ⌘/ |

完整列表见[快捷键](/docs/shortcuts/)，以应用内快捷键面板（⌘/）为准。

## 融入 macOS

- **系统通知**：你在忙别的事时，任务完成、失败、等你回答或批准，都会推送 macOS 通知；点一下直接回到那个会话。
- **快速查看（Quick Look）**：对话里的图片和文件用系统快速查看预览，和在 Finder 里看一样。
- **Finder**：交付文件一键「在 Finder 中显示」，工作区也可以直接在 Finder 中打开。
- **用你的编辑器打开**：在设置里选好应用，工具栏的 Workspace 按钮就用它打开当前会话的目录。
- **拖拽即附件**：把文件或图片拖进输入框，或直接粘贴图片；工作区外的文件也会真正上传。
- **内置终端**：⌘J 在会话下方呼出终端面板，支持多个标签页。
- **跟随你的 Mac**：浅色、深色或跟随系统；尊重「减少动态效果」。

## 看得清每一步

- **改动文件卡片**：每轮结束列出改了哪些文件、增删多少行，点开逐文件看 diff。
- **轮次导航**：沿着左侧轮次条跳转，翻入更早的历史；查找支持上一个 / 下一个。
- **轨迹检查器**：时间线展示每一步的耗时与细节，可缩放、可拖动聚焦。
- **会话管理**：置顶、手动排序、按工作区分组、归档与恢复、导出会话日志。

## 接入你的 dsh，一站式管理扩展

它不是另一套 DSH，而是**同一个 dsh 服务的原生客户端**：

1. 启动时先探测本机 `3080` 端口，已有 dsh 在跑（比如终端里的 `dsh web`）就直接接入。
2. 没有在跑的服务，就用你已安装的 dsh 启动并托管；电脑上完全没有 dsh 时，征得你同意后安装 Node.js 与 `@deepseek-ai/dsh`。
3. 发现新版 dsh 时提示升级。

会话、模型配置、插件与 Web 端完全互通。扩展也都在这里打开：

| 入口 | 能做什么 |
| --- | --- |
| 设置 → 浏览器 | 安装浏览器控制插件、检测 Chrome 扩展，显示连接状态与失败原因 |
| 设置 → 电脑操作 | 安装电脑操作插件，检查 KimiCU.app 与授权，直达系统设置 |
| 设置 → 插件 | 「插件市场」与「内置插件」，启用、停用或移除插件 |
| 侧栏 → 移动端访问 | 生成配对二维码，让手机连上这台 Mac |
